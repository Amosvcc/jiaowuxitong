# 用户使用说明

## 1. 新建项目

1. 启动程序。
2. 点击工具栏或菜单栏中的“新建”。
3. 程序会创建一个默认 `10 x 5` 的空表格。

## 2. 导入 CSV / Excel

1. 点击“导入”。
2. 选择 `.csv` 或 `.xlsx` 文件。
3. 程序默认将第一行识别为列名。
4. 导入成功后，表格会立即刷新显示。

说明：

- 空列名会自动补为 `字段1`、`字段2`。
- 重复列名会自动追加编号，例如 `状态_2`。

## 3. 编辑表格

- 双击单元格可直接编辑。
- 新值会直接覆盖旧值。
- 点击“新增行”可追加一行。
- 点击“新增列”可追加一列。

## 4. 设置列下拉选项

1. 选中某列中的任意单元格，点击“列设置”。
2. 或右键点击列表头，选择“列设置”。
3. 在弹窗中可修改：
   - 列名
   - 字段类型
   - 下拉选项
   - 是否允许自定义值
4. 当字段类型为“下拉”时，该列编辑器会显示下拉框。

## 5. 搜索

1. 在顶部搜索框中输入关键词。
2. 按 `Enter` 开始搜索。
3. 使用“上一条”“下一条”定位匹配单元格。
4. 点击“清除”可取消高亮并清空搜索结果。

说明：

- 搜索不区分大小写。
- 搜索支持部分匹配。
- 已终止行也参与搜索。

## 6. 终止 / 恢复行

1. 选中一个或多个单元格。
2. 点击“终止行”可冻结对应行。
3. 点击“恢复行”可恢复为正常状态。

说明：

- 已终止行默认禁止编辑。
- 已终止行会显示明显的背景色和行头标识。
- 已终止行仍参与搜索、导出和统计。

## 7. 字段统计

1. 点击“统计”。
2. 选择一个统计字段。
3. 选择是否包含已终止行。
4. 选择是否忽略空值。
5. 点击“生成统计”。

统计结果包含：

- 字段值
- 数量
- 占比

## 8. 导出数据

### 导出原始表格

1. 点击“导出”。
2. 选择 `.csv` 或 `.xlsx`。
3. 保存后可得到当前表格数据。

### 导出统计结果

1. 先打开“统计”窗口并生成结果。
2. 点击“导出统计结果”。
3. 选择 `.csv` 或 `.xlsx` 保存。

## 9. 保存 / 打开 `.dasproj`

### 保存项目

- 点击“保存”保存当前项目。
- 如果是第一次保存，会提示选择保存位置。
- 项目文件扩展名为 `.dasproj`。

### 打开项目

1. 点击“打开”。
2. 选择已有 `.dasproj` 文件。
3. 程序会恢复表格数据、列设置、行终止状态和下拉选项配置。

## 10. 未保存提示

- 编辑单元格
- 新增行
- 新增列
- 修改列设置
- 导入文件
- 终止 / 恢复行

以上操作都会让项目进入未保存状态。关闭窗口、新建项目或打开其他项目时，程序会提示是否先保存。
