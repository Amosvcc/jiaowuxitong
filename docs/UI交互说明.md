# UI 交互说明

## 1. 主窗口

主窗口默认大小：1200 × 800。

主窗口包含：

- 菜单栏
- 工具栏
- 数据表格
- 状态栏

## 2. 工具栏

建议工具栏按钮顺序：

```text
[新建] [打开] [导入] [保存] [导出] | [新增行] [新增列] [删除] | [终止行] [恢复行] | [列设置] [统计] | 搜索框
```

## 3. 表格区域

表格区域使用 `QTableView`。

交互规则：

- 双击单元格进入编辑。
- 按 Enter 提交编辑。
- 按 Esc 取消编辑。
- 右键行号显示行菜单。
- 右键列头显示列菜单。

## 4. 行右键菜单

```text
终止此行
恢复此行
删除此行
```

多选行时：

```text
批量终止
批量恢复
批量删除
```

## 5. 列右键菜单

```text
列设置
修改列名
批量更新此列
删除此列
```

## 6. 已终止行视觉表现

建议：

- 行背景显示浅灰色。
- 行号旁显示锁定图标或 `[终止]`。
- 鼠标悬停提示：该行已终止，不参与自动更新。

## 7. 搜索

搜索框位于顶部工具栏右侧：

```text
搜索：[________] [上一条] [下一条] [清除]
```

搜索结果：

- 匹配单元格高亮。
- 状态栏显示：`找到 12 个匹配项，当前第 3 个`。

## 8. 列设置窗口

字段：

- 列名
- 字段类型
- 下拉选项列表
- 是否允许自定义值

按钮：

- 新增选项
- 删除选项
- 上移
- 下移
- 确定
- 取消

## 9. 统计窗口

字段：

- 选择统计字段
- 是否包含已终止行
- 是否忽略空值

按钮：

- 生成统计
- 导出统计结果

结果表：

```text
字段值 | 数量 | 占比
```
## 撤销操作

- 工具栏提供“撤销”按钮。
- 支持 `Ctrl+Z` 快捷键撤销上一步数据修改。
- 撤销用于恢复误删除、误编辑、新增行列、终止/恢复行、列设置和数据更新等操作。

## 新增行列

- 点击“新增行”时，默认在当前选中行后方插入新行；未选中行时追加到末尾。
- 点击“新增列”时，默认在当前选中列后方插入新列；未选中列时追加到末尾。

## 列标题快速筛选

- 每个列标题右侧显示一个小三角。
- 点击小三角直接打开该列筛选对话框，可快速勾选列值进行筛选。
- 右键列标题仍保留筛选、清除筛选、列设置和删除列菜单。
