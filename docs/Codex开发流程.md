# Codex 开发流程建议

## 1. 每次只让 Codex 做一个任务

不要一次性让 Codex 完成整个 V1.0。建议按 `docs/Codex任务提示词.md` 的任务顺序逐步推进。

## 2. 每轮任务完成后检查

每一轮完成后检查：

1. 是否能运行 `python main.py`。
2. 是否符合当前任务验收标准。
3. 是否改动了不该改动的文件。
4. 是否破坏了已有功能。

## 3. 推荐使用方式

每轮给 Codex 的提示格式：

```text
请阅读 AGENTS.md 和 docs 中相关文档。
本轮只完成“任务 X：xxx”。
不要实现后续任务。
完成后运行基础检查，并说明修改内容。
```

## 4. 发现问题时的修复提示

```text
上一次实现后出现以下问题：
1. xxx
2. xxx

请只修复这些问题，不要重构无关代码，不要实现新功能。
修复后说明改动文件和验证方式。
```

## 5. 代码审查提示

```text
请审查当前项目代码，重点检查：
1. 是否违反 AGENTS.md 架构规则。
2. 是否把业务逻辑写进 main_window.py。
3. 是否错误使用 QTableWidget。
4. 是否存在明显异常未处理。
5. 是否存在可以补充测试的核心逻辑。

本轮只给出审查意见，不要修改代码。
```
