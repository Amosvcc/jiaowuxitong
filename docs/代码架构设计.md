# 数据分析软件 V1.0 代码架构设计

## 1. 总体架构

V1.0 使用以下技术组合：

```text
Python 3.11+
PySide6
SQLite
pandas
openpyxl
PyInstaller
```

整体架构采用分层设计：

```text
界面层 UI Layer
    ↓
表格模型层 Model/View Layer
    ↓
业务服务层 Service Layer
    ↓
数据访问层 Repository / DAO Layer
    ↓
SQLite / CSV / Excel 文件
```

## 3. 模块职责

| 模块 | 职责 |
|---|---|
| `app/ui/` | 主窗口、菜单栏、工具栏、弹窗、用户交互 |
| `app/models/` | Column、Row、Cell、Project、StatisticsItem |
| `app/services/` | 导入导出、统计、搜索、行终止、列设置等业务逻辑 |
| `app/repositories/` | SQLite 数据库读写 |
| `app/io/` | CSV / Excel 文件读取和导出 |
| `app/core/` | 常量、异常、工具函数 |

## 4. 表格实现要求

表格必须使用：

```text
QTableView + QAbstractTableModel + Delegate
```

不建议使用 `QTableWidget`，因为后续大数据量、下拉代理、行终止视觉规则会更难维护。

## 5. 核心数据结构

建议使用：

```python
self.columns: list[Column]
self.rows: list[Row]
self.cells: dict[tuple[int, int], str]
```

其中：

```text
key = (row_id, column_id)
value = 单元格文本
```

## 6. 核心数据流

### 导入文件

```text
用户点击导入
    ↓
MainWindow 打开文件选择框
    ↓
ImportExportService.import_file(path)
    ↓
CSVAdapter / ExcelAdapter 读取为 DataFrame
    ↓
TableService 将 DataFrame 转为 Project
    ↓
TableModel 加载数据
    ↓
QTableView 刷新显示
```

### 编辑单元格

```text
用户编辑单元格
    ↓
TableModel.setData(index, value)
    ↓
检查该行是否已终止
    ↓
检查该列是否有下拉约束
    ↓
更新 cells[(row_id, column_id)]
    ↓
标记项目为未保存
    ↓
通知界面刷新
```

### 保存项目

```text
用户点击保存
    ↓
ProjectService.save_project()
    ↓
Repository 写入 SQLite
    ↓
保存 columns / rows / cells / settings
```

## 7. 第一版可运行骨架目标

完成后应满足：

1. 可以通过 `python main.py` 启动程序。
2. 主窗口标题显示“数据分析软件 V1.0”。
3. 窗口中显示一个表格。
4. 表格默认包含若干空行和空列。
5. 用户可以编辑单元格。
6. 点击“新增行”可以增加一行。
7. 点击“新增列”可以增加一列。
8. 程序退出时无异常。
