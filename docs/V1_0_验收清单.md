# V1.0 验收清单

## 主程序

- [ ] 可以通过 `python main.py` 启动
- [ ] 主窗口标题正确
- [ ] 程序退出无异常
- [ ] 支持 Windows 10 / Windows 11

## 表格

- [ ] 表格可以显示多行多列
- [ ] 单元格可以编辑
- [ ] 修改后新值覆盖旧值
- [ ] 可以新增行
- [ ] 可以新增列
- [ ] 可以删除行
- [ ] 可以删除列
- [ ] 可以修改列名

## 导入导出

- [ ] 可以导入 CSV
- [ ] 可以导入 `.xlsx`
- [ ] 可以导出 CSV
- [ ] 可以导出 `.xlsx`
- [ ] 中文内容不乱码
- [ ] 中文路径可以正常打开和保存

## 项目保存

- [ ] 可以保存为 `.dasproj`
- [ ] 可以重新打开 `.dasproj`
- [ ] 重新打开后行列数据一致
- [ ] 重新打开后列设置一致
- [ ] 重新打开后下拉选项一致
- [ ] 重新打开后行终止状态一致

## 搜索

- [ ] 可以通过搜索框搜索全表数据
- [ ] 匹配结果可以高亮
- [ ] 可以跳转上一条和下一条
- [ ] 清除搜索后高亮消失
- [ ] 搜索包含已终止行

## 下拉选项

- [ ] 可以打开列设置窗口
- [ ] 可以为某一列设置下拉选项
- [ ] 编辑该列单元格时显示下拉框
- [ ] 下拉选项可以保存到项目文件
- [ ] 重新打开项目后下拉选项仍存在

## 行终止

- [ ] 可以终止一行
- [ ] 可以恢复已终止行
- [ ] 已终止行有视觉标识
- [ ] 已终止行默认不能编辑
- [ ] 批量更新跳过已终止行
- [ ] 新增列不自动填充已终止行
- [ ] 已终止行仍参与搜索
- [ ] 已终止行仍参与导出

## 数据更新 / 表合并

- [ ] 可以从主窗口打开“数据更新”对话框
- [ ] 可以选择 CSV 更新表
- [ ] 可以选择 Excel 更新表
- [ ] 可以选择主表匹配字段和更新表匹配字段
- [ ] 主表匹配字段重复时会阻止更新并提示错误
- [ ] 更新表匹配字段重复时会阻止更新并提示错误
- [ ] 空匹配值不会参与匹配
- [ ] `overwrite_existing=False` 时不覆盖主表已有值
- [ ] `overwrite_existing=True` 时可覆盖主表已有值
- [ ] `ignore_empty_values=True` 时更新表空值不会覆盖主表
- [ ] `add_missing_columns=True` 时可自动新增主表缺失列
- [ ] `add_missing_columns=False` 时不会新增主表缺失列
- [ ] `append_unmatched_rows=True` 时可追加未匹配行
- [ ] `append_unmatched_rows=False` 时不会追加未匹配行
- [ ] 默认不更新已终止行
- [ ] `update_terminated_rows=True` 时可更新已终止行
- [ ] 仅打开对话框、选择文件、预览、取消操作不会标记 dirty
- [ ] 实际发生新增列、更新单元格、追加行时才标记 dirty

## 统计

- [ ] 可以选择一个字段进行统计
- [ ] 可以统计字段值数量
- [ ] 可以显示字段值占比
- [ ] 可以设置是否包含已终止行
- [ ] 可以设置是否忽略空值
- [ ] 可以导出统计结果
## 数据透视 / 交叉统计

- [ ] 可以从主窗口打开“数据透视 / 交叉统计”对话框
- [ ] 可以选择行字段和列头字段生成二维计数结果
- [ ] 默认忽略空行字段
- [ ] 默认忽略空列头字段
- [ ] 默认不包含已终止行
- [ ] 可以选择是否包含已终止行
- [ ] 可以选择是否按标签展开列头字段
- [ ] 标签展开支持分号、逗号、顿号、斜杠、竖线和换行
- [ ] 标签展开时空标签会被忽略
- [ ] 标签展开时同一单元格内重复标签只计一次
- [ ] 行字段顺序按首次出现顺序展示
- [ ] 列头字段顺序按首次出现顺序展示
- [ ] 可以显示行合计
- [ ] 可以显示列合计
- [ ] 可以导出数据透视结果到 CSV
- [ ] 可以导出数据透视结果到 Excel
- [ ] 打开对话框、生成结果、导出结果、关闭对话框都不改变项目 dirty 状态
