# V1.0 验收清单

> 状态：V1.0 已完成（更新日期：2026-05-16）

## 主程序

- [x] 可以通过 `python main.py` 启动
- [x] 主窗口标题正确
- [x] 程序退出无异常
- [x] 支持 Windows 10 / Windows 11

## 表格

- [x] 表格可以显示多行多列
- [x] 单元格可以编辑
- [x] 修改后新值覆盖旧值
- [x] 可以新增行
- [x] 可以新增列
- [x] 可以删除行
- [x] 可以删除列
- [x] 可以修改列名

## 导入导出

- [x] 可以导入 CSV
- [x] 可以导入 `.xlsx`
- [x] 可以导出 CSV
- [x] 可以导出 `.xlsx`
- [x] 中文内容不乱码
- [x] 中文路径可以正常打开和保存

## 项目保存

- [x] 可以保存为 `.dasproj`
- [x] 可以重新打开 `.dasproj`
- [x] 重新打开后行列数据一致
- [x] 重新打开后列设置一致
- [x] 重新打开后下拉选项一致
- [x] 重新打开后行终止状态一致

## 搜索

- [x] 可以通过搜索框搜索全表数据
- [x] 匹配结果可以高亮
- [x] 可以跳转上一条和下一条
- [x] 清除搜索后高亮消失
- [x] 搜索包含已终止行

## 下拉选项

- [x] 可以打开列设置窗口
- [x] 可以为某一列设置下拉选项
- [x] 编辑该列单元格时显示下拉框
- [x] 下拉选项可以保存到项目文件
- [x] 重新打开项目后下拉选项仍存在

## 行终止

- [x] 可以终止一行
- [x] 可以恢复已终止行
- [x] 已终止行有视觉标识
- [x] 已终止行默认不能编辑
- [x] 批量更新跳过已终止行
- [x] 新增列不自动填充已终止行
- [x] 已终止行仍参与搜索
- [x] 已终止行仍参与导出

## 数据更新 / 表合并

- [x] 可以从主窗口打开“数据更新”对话框
- [x] 可以选择 CSV 更新表
- [x] 可以选择 Excel 更新表
- [x] 可以选择主表匹配字段和更新表匹配字段
- [x] 主表匹配字段重复时会阻止更新并提示错误
- [x] 更新表匹配字段重复时会阻止更新并提示错误
- [x] 空匹配值不会参与匹配
- [x] `overwrite_existing=False` 时不覆盖主表已有值
- [x] `overwrite_existing=True` 时可覆盖主表已有值
- [x] `ignore_empty_values=True` 时更新表空值不会覆盖主表
- [x] `add_missing_columns=True` 时可自动新增主表缺失列
- [x] `add_missing_columns=False` 时不会新增主表缺失列
- [x] `append_unmatched_rows=True` 时可追加未匹配行
- [x] `append_unmatched_rows=False` 时不会追加未匹配行
- [x] 默认不更新已终止行
- [x] `update_terminated_rows=True` 时可更新已终止行
- [x] 仅打开对话框、选择文件、预览、取消操作不会标记 dirty
- [x] 实际发生新增列、更新单元格、追加行时才标记 dirty

## 统计

- [x] 可以选择一个字段进行统计
- [x] 可以统计字段值数量
- [x] 可以显示字段值占比
- [x] 可以设置是否包含已终止行
- [x] 可以设置是否忽略空值
- [x] 可以导出统计结果
## 数据透视 / 交叉统计

- [x] 可以从主窗口打开“数据透视 / 交叉统计”对话框
- [x] 可以选择行字段和列头字段生成二维计数结果
- [x] 默认忽略空行字段
- [x] 默认忽略空列头字段
- [x] 默认不包含已终止行
- [x] 可以选择是否包含已终止行
- [x] 可以选择是否按标签展开列头字段
- [x] 标签展开支持分号、逗号、顿号、斜杠、竖线和换行
- [x] 标签展开时空标签会被忽略
- [x] 标签展开时同一单元格内重复标签只计一次
- [x] 行字段顺序按首次出现顺序展示
- [x] 列头字段顺序按首次出现顺序展示
- [x] 可以显示行合计
- [x] 可以显示列合计
- [x] 可以导出数据透视结果到 CSV
- [x] 可以导出数据透视结果到 Excel
- [x] 打开对话框、生成结果、导出结果、关闭对话框都不改变项目 dirty 状态

## 列标题筛选 / 快速筛选

- [x] 可以通过列标题右键打开当前列筛选对话框
- [x] 筛选对话框显示当前列唯一值和数量
- [x] 空单元格显示为“空白”并可参与筛选
- [x] 单列多值筛选使用 OR 逻辑
- [x] 多列筛选使用 AND 逻辑
- [x] 可以清除当前列筛选
- [x] 可以清除全部筛选
- [x] 筛选结果为空时表格显示空结果且不报错
- [x] 筛选、清除筛选、打开筛选对话框不修改项目 dirty 状态
- [x] 已终止行默认参与筛选，且在筛选结果中保持不可编辑和原有样式
- [x] 搜索和筛选同时存在时，搜索高亮和导航只作用于当前可见行
- [x] 使用 QTableView + QAbstractTableModel + QSortFilterProxyModel，不使用 QTableWidget
## 撤销操作

- [x] 工具栏提供“撤销”按钮
- [x] 支持 `Ctrl+Z` 快捷键撤销上一步数据修改
- [x] 删除行后可以撤销恢复
- [x] 删除列后可以撤销恢复

- [x] 选中单元格后点击“新增行”，新行插入到当前行后方
- [x] 选中单元格后点击“新增列”，新列插入到当前列后方
