# 数据分析软件 V1.0 功能规格说明书

## 1. 软件定位

本软件是一款运行在 Windows 上的轻量级数据分析与数据管理工具。

软件界面整体类似 Excel 表格，用户可以导入数据、直接编辑数据、设置字段下拉选项、搜索数据、终止指定行的数据更新，并基于指定字段生成统计结果。

V1.0 的目标不是替代 Excel，而是实现一个针对结构化数据维护和简单统计分析的专用工具。

## 2. V1.0 开发目标

1. 支持表格数据的导入、展示、编辑和保存。
2. 支持用户像使用 Excel 一样直接编辑多行多列数据。
3. 支持顶部搜索框快速查找表格数据。
4. 支持为每一列设置下拉选项。
5. 支持将某一行标记为“已终止”。
6. 行终止后，该行不再受新增列、批量更新等操作影响。
7. 修改某一列数据时，新值直接覆盖旧值。
8. 支持选择某个字段进行分类计数统计。
9. 支持导出统计结果。

## 3. 技术方案

- Python 3.11+
- PySide6
- SQLite
- pandas
- openpyxl
- PyInstaller

## 5. 核心功能

### 5.1 表格编辑

- 多行多列展示。
- 单元格直接编辑。
- 新增行。
- 新增列。
- 删除行。
- 删除列。
- 修改列名。
- 修改单元格数据时直接覆盖旧值。

### 5.2 数据导入

V1.0 支持：

- CSV
- Excel `.xlsx`

导入规则：

1. 默认将第一行识别为列名。
2. 后续行识别为数据行。
3. 空列名自动命名为 `字段1`、`字段2` 等。
4. 重复列名自动追加编号，例如 `状态`、`状态_2`。
5. 空单元格保存为空字符串。
6. 导入后所有行默认为“正常”状态。
7. 导入后所有列默认为“文本”类型。

### 5.3 搜索

- 顶部工具栏提供搜索框。
- 默认搜索整个表格。
- 搜索不区分大小写。
- 支持部分匹配。
- 匹配到的单元格高亮显示。
- 支持上一条 / 下一条跳转。

### 5.4 列下拉选项

每一列可以设置可选值。

列设置内容：

- 列名。
- 字段类型：文本 / 数字 / 日期 / 下拉选项。
- 下拉选项列表。
- 是否允许输入非下拉选项值。

### 5.5 行终止

每一行有两种状态：

| 状态 | 说明 |
|---|---|
| 正常 | 行数据可以编辑，可以参与批量更新和新增列默认填充 |
| 已终止 | 行数据被冻结，不参与后续自动更新 |

已终止行规则：

- 默认禁止手动编辑。
- 批量更新时跳过。
- 新增列时不自动填充。
- 搜索时仍参与。
- 导出时仍参与。
- 统计时默认参与，可配置排除。

### 5.6 字段统计

用户选择某个字段，软件统计该字段下不同数据值出现的次数。

统计结果包含：

- 字段值
- 数量
- 占比

示例：

| 状态 | 数量 | 占比 |
|---|---:|---:|
| 已完成 | 20 | 44.44% |
| 进行中 | 12 | 26.67% |
| 未开始 | 8 | 17.78% |

### 5.7 导出

支持导出：

- 原始数据 CSV / Excel
- 统计结果 CSV / Excel

## 6. 暂不实现

V1.0 暂不实现：

- 多用户协作
- 云同步
- 用户登录和权限管理
- Excel 公式系统
- 复杂数据透视表
- 多字段交叉统计
- 图表分析
- 自动更新
- 插件系统
- 操作历史回滚
