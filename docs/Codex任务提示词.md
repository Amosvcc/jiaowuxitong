# Codex 任务提示词

以下提示词用于让 Codex 按阶段开发。每次只复制一个任务给 Codex。

---

## 任务 1：创建项目骨架

请阅读 `AGENTS.md`、`docs/功能规格说明书.md` 和 `docs/代码架构设计.md`，然后创建 V1.0 第一阶段项目骨架。

要求：

1. 创建 `main.py`。
2. 创建 `app/ui/main_window.py`。
3. 创建 `app/ui/table_view.py`。
4. 创建 `app/ui/table_model.py`。
5. 创建必要的 `__init__.py`。
6. 程序必须能通过 `python main.py` 启动。
7. 主窗口标题为“数据分析软件 V1.0”。
8. 主窗口默认大小为 1200 × 800。
9. 暂时不要实现导入、保存、统计功能。
10. 完成后说明修改了哪些文件，以及如何运行。

验收标准：

- `python main.py` 可以启动。
- 可以看到主窗口。
- 程序退出无异常。

---

## 任务 2：实现可编辑表格

请在当前项目骨架上实现 `QTableView + QAbstractTableModel` 的基础可编辑表格。

要求：

1. 默认显示 3 行 3 列。
2. 列名为 `字段1`、`字段2`、`字段3`。
3. 单元格可以编辑。
4. 新值提交后直接覆盖旧值。
5. 工具栏提供“新增行”和“新增列”按钮。
6. 点击“新增行”后在表格末尾新增空行。
7. 点击“新增列”后在表格末尾新增空列。
8. 不要使用 `QTableWidget`。
9. 修改后保持程序可运行。

验收标准：

- 可以编辑任意单元格。
- 可以新增行。
- 可以新增列。
- 程序退出无异常。

---

## 任务 3：引入业务数据模型

请将当前表格内部的二维 list 数据结构升级为业务模型。

要求：

1. 创建 `app/models/column.py`，定义 `Column`。
2. 创建 `app/models/row.py`，定义 `Row`。
3. 创建 `app/models/cell.py`，定义 `Cell`。
4. 创建 `app/models/project.py`，定义 `Project`。
5. `DataTableModel` 内部改为使用：
   - `columns: list[Column]`
   - `rows: list[Row]`
   - `cells: dict[tuple[int, int], str]`
6. 保持现有表格编辑、新增行、新增列功能正常。
7. 暂时不要实现 SQLite。

验收标准：

- `python main.py` 可以启动。
- 表格仍然可以编辑。
- 新增行和新增列仍然有效。

---

## 任务 4：实现 CSV 导入导出

请实现 CSV 导入导出功能。

要求：

1. 创建 `app/io/csv_adapter.py`。
2. 创建 `app/services/import_export_service.py`。
3. 在工具栏增加“导入”和“导出”按钮。
4. 支持导入 `.csv` 文件。
5. 默认第一行为列名。
6. 空单元格保存为空字符串。
7. 导入后刷新表格。
8. 支持导出当前表格为 `.csv`。
9. 支持中文路径和中文内容。
10. 导入失败时弹出错误提示，且不能破坏当前表格数据。

验收标准：

- 可以导入 `sample_data/demo.csv`。
- 可以编辑导入后的数据。
- 可以导出为新的 CSV 文件。

## 任务 6：实现 SQLite 项目保存与打开

请实现 `.dasproj` 项目保存和打开。

要求：

1. 创建 `app/repositories/database.py`。
2. 创建 `app/repositories/schema.py`。
3. 创建 `project_repository.py`、`column_repository.py`、`row_repository.py`、`cell_repository.py`。
4. 使用 `docs/数据库表结构.sql` 中的表结构。
5. 创建 `app/services/project_service.py`。
6. 工具栏增加“新建”、“打开”、“保存”。
7. 保存为 `.dasproj` 文件。
8. 重新打开项目后，数据应保持一致。
9. CSV / Excel 仍然只作为导入导出格式，不作为内部项目格式。

验收标准：

- 可以保存项目。
- 可以重新打开项目。
- 重新打开后行、列、单元格数据一致。

## 任务 7：实现行终止机制

请实现行终止和恢复功能。

要求：

1. 每一行有 `is_terminated` 状态。
2. 支持选中行后点击“终止行”。
3. 支持选中已终止行后点击“恢复行”。
4. 已终止行显示浅灰背景。
5. 已终止行默认禁止编辑。
6. 新增列时已终止行不自动填充默认值。
7. 后续批量更新必须跳过已终止行。
8. 保存项目时保存行终止状态。
9. 重新打开项目后终止状态仍然存在。

验收标准：

- 可以终止行。
- 已终止行不可编辑。
- 可以恢复行。
- 保存和打开后状态不丢失。

---

## 任务 8：实现列设置与下拉选项

请实现列设置和下拉选项功能。

要求：

1. 创建 `app/ui/dialogs/column_settings_dialog.py`。
2. 创建 `app/ui/delegates.py`。
3. 支持修改列名。
4. 支持设置字段类型：文本 / 数字 / 日期 / 下拉选项。
5. 支持为列设置下拉选项。
6. 下拉选项不能重复，不能为空。
7. 下拉列编辑时显示 `QComboBox`。
8. 支持是否允许自定义值。
9. 保存项目时保存列设置。
10. 重新打开项目后列设置仍然存在。

验收标准：

- 可以给某一列设置下拉选项。
- 编辑该列时显示下拉框。
- 保存和打开后下拉配置不丢失。

## 任务 10：实现字段统计

请实现单字段统计功能。

要求：

1. 创建 `app/services/statistics_service.py`。
2. 创建 `app/models/statistics_result.py`。
3. 创建 `app/ui/dialogs/statistics_dialog.py`。
4. 工具栏增加“统计”按钮。
5. 用户可以选择一个字段。
6. 用户可以选择是否包含已终止行。
7. 用户可以选择是否忽略空值。
8. 统计结果包含：字段值、数量、占比。
9. 按数量从高到低排序。
10. 支持导出统计结果为 CSV / Excel。

验收标准：

- 可以选择字段统计数量。
- 可以显示占比。
- 可以导出统计结果。
